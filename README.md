# 🧮 لعبة الرياضيات (Math Game)

تطبيق تفاعلي لاختبار وتطوير المهارات الحسابية والرياضية مكتوب بلغة **C++** عبر الشاشة النصية (Console).

---

## 📌 وصف المشروع

هذا النظام يتيح للاعب التحدي في حل المسائل الحسابية واختبار سرعة بديهته:

* ❓ **تحديد عدد الأسئلة:** إمكانية اختيار عدد الأسئلة المطلوبة (من 1 إلى 10).
* 📊 **تحديد مستوى الصعوبة:** اختيار المستوى المناسب (سهل Easy، متوسط Med، صعب Hard، أو مشكل Mix).
* ➕ **تحديد نوع العمليات:** اختيار نوع العملية (جمع، طرح، ضرب، قسمة، أو مختلط).
* 🎲 **توليد أسئلة عشوائية:** إنشاء أرقام وعمليات رياضية عشوائياً بناءً على المستوى المختار.
* 🎨 **تأثيرات تفاعلية:** تغيير لون الشاشة للون الأخضر عند الإجابة الصحيحة، والأحمر مع صوت تنبيه عند الإجابة الخاطئة.
* 🏆 **تقييم النتيجة النهائية:** عرض تقرير شامل بالإجابات الصحيحة والخاطئة وحالة النتيجة (Pass / Fault / Draw).

تم تطويره كجزء من كورس التفكير المنطقي والحلول البرمجية مع الدكتور محمد أبو هدهود.

---

## ✨ المميزات

* 🎲 **توليد الأعداد عشوائياً (Random Generation):** إنشاء معادلات حسابية متغيرة في كل جولة.
* 🎚️ **مستويات صعوبة متعددة (Difficulty Levels):** التحكم في نطاق الأرقام طبقاً لمستوى اللاعب.
* 🎨 **تغذية بصرية وصوتية (Visual & Audio Feedback):** استخدام `system("color")` والتنبيه الصوتي `\a` لزيادة الحماس.
* 📊 **سجل الإحصائيات (Game Summary):** حوسبة دقيقة للإجابات وحفظ نتائج الجولات عبر الـ `struct`.

---

## 🛠️ التقنيات المستخدمة

* **C++** (لغة البرمجة الأساسية)
* **Enums & Structs** (لتمثيل المستويات، العمليات، وهيكلة بيانات اللعبة)
* **Control Flow & Loops** (لإدارة منطق الشروط وإعادة اللعب)
* **C Standard Libraries** (`cstdlib`, `ctime` للتعامل مع العشوائية)
